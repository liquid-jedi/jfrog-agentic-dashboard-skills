Install

Recommended path is APM, which gives you a lockfile and reproducible installs across a team.

# 1. Install APM
curl -sSL https://aka.ms/apm-unix | sh

# 2. Create a reporting workspace
mkdir -p ~/ciso-reporting && cd ~/ciso-reporting
apm init -y --target claude,codex,cursor

# 3. Install the skill
apm install liquid-jedi/jfrog-agentic-dashboard-skills/packages/apm/jfrog-ciso-report#v4.3.0

Then ask your agent: Generate a weekly CISO report for server <id>. Save under ~/ciso-reports.

On a restricted network, download jfrog-ciso-report-v4.3.0.zip from the Assets of the latest release — not “Source code”, which is the whole repository — then unzip it and run apm install ./jfrog-ciso-report --target claude,cursor,codex.

What you need

Platform

  • JFrog Platform with Xray — indexed repos, watches, policies, violations
  • JFrog Curation — required; the run's final proof gate checks it
  • JFrog CLI configured (jf config show)

Local

  • python3 — collection, transform and render
  • node plus Chrome, Chromium or Edge — PDF export (skip with html only / CISO_PDF_MODE=none)
  • macOS or Linux natively; Windows via WSL2
